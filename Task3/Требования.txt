Требования к внешней интеграции:
1. Безопасности
Все запросы между PropDevelopment и платформой партнёра должны передаваться по HTTPS/TLS 1.2+.
Должна применяться модель Zero Trust для всех внешних интеграций.
Данные о пользователях (включая биометрию и номера авто) не должны храниться на стороне PropDevelopment дольше необходимого срока.
Логирование всех интеграционных запросов с сохранением идентификатора пользователя, типа операции и временной метки.
Мониторинг и автоматическое оповещение о подозрительных действиях (SIEM).

2. Протоколы аутентификации и авторизации
OAuth 2.0 для авторизации мобильного приложения при доступе к API платформы партнёра.
OpenID Connect для идентификации пользователей.
JWT (JSON Web Token) с цифровой подписью для проверки подлинности запросов.

3. Организация взаимодействия систем
Сначала Мобильное приложение собственников запрашивает токен у Identity Provider PropDevelopment
далее токен передаётся в tenant-core-app. tenant-core-app проверяет права и пересылает запрос в созданный нами
допустим будет называться smartHome-integrationService-app.
smartHome-integrationService-app конвертирует запрос в формат API партнёра и отправляет его по защищённому каналу затем
ответы от партнёра проходят обратный путь и возвращаются в приложение.
